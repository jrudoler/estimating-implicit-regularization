01 — THE BALANCE

Regularization changes the optimum.

Adding a regularization penalty changes the objective being minimized. In this example, the penalty favors smaller weights and shifts the optimum away from the minimum of the training loss. At the new optimum, the loss and penalty gradients cancel.

Reverse-engineering the regularization.

We can exploit this structure to reverse-engineer the regularization. Given trained weights and the training loss, we compute the remaining loss gradient and fit a candidate regularizer whose gradient cancels it. For the L₂ penalty shown here, this means estimating its strength λ. The estimate explains the observed weights within the chosen regularizer family; it need not identify the mechanism that produced them.

02 — REVERSE ENGINEERING

Fix the weights. Estimate the penalty.

In Figure 1, we held λ fixed and found the weights. Here we hold the observed weight θ̂ fixed and find λ. As the penalty changes, the minimum of the combined objective moves toward the observed weight. The loss gradient at θ̂ stays constant; the penalty gradient changes until it cancels it.

The inverse calculation and its limits

We minimize E(λ) = [L′(θ̂) + 2λθ̂]² over λ ≥ 0 while holding θ̂ fixed. For this loss, L′(θ̂) = θ̂ − 2, giving λ̂ = max(0, (2 − θ̂)/(2θ̂)) when θ̂ ≠ 0. “Estimate λ” animates from the current guess to this exact least-squares solution; it is not a simulation of an iterative optimizer.

For 0 < θ̂ ≤ 2, the gradients can cancel exactly. Outside that interval, nonnegative ridge cannot explain the observed weight as an optimum: its best fit leaves a residual. At θ̂ = 0, every λ supplies the same zero penalty gradient, so λ is unidentifiable. A fitted coefficient is an explanation within the chosen family, not evidence that this mechanism generated the weights.

A balance is a clue, not a unique explanation.

These quadratic bowls are convex, so a zero net gradient identifies the minimum. A neural network is more complicated: gradient cancellation alone establishes stationarity, not a global minimum. And several regularizers may explain the same endpoint.

What exactly are we estimating?

We use mean squared error L = (1/n) Σ(fθ(xᵢ) − yᵢ)² and R = λ‖θ‖², penalizing all parameters, including biases (3 × width + 1 parameters). Full-batch gradient descent runs for up to 20,000 steps. The learning rate is 0.04 × 16 / width (0.04, 0.02, or 0.01) to keep wider networks stable. The data and initialization are reproducible for each seed.

λ̂ = max(0, −θᵀ∇L / (2‖θ‖²))

This is a nonnegative least-squares projection of −∇L onto 2θ. “Gradient explained” is 1 − ‖∇L + 2λ̂θ‖² / ‖∇L‖². It is a fit diagnostic, not predictive R². Near-zero weights make the coefficient unidentifiable; a near-zero loss gradient makes the explained fraction uninformative. We display a dash for unavailable diagnostics.

For ReLU, we use a zero derivative at a kink. Tanh uses its smooth derivative, 1 − tanh²(z). Finite training time and nonsmoothness can leave a residual even when the loss appears stable. This experiment demonstrates explicit-penalty recovery, not proof that an arbitrary implicit bias is ridge regularization.

FROM A SANITY CHECK TO A SCIENTIFIC QUESTION

What if the penalty was never written down?

Early stopping, dropout, and optimization choices can all change what a model learns. The paper asks whether a proposed explicit regularizer can explain those effects—and whether retraining with it reproduces the original behavior.

Our dropout experiments offer an important limit: a scalar ridge penalty explains only a small part of the residual gradient, and replacing dropout with that fitted penalty does not recover the original test performance. Estimating a coefficient is only the beginning. Testing the explanation is the point.
