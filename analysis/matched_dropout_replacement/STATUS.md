# Matched dropout replacement — completed 2026-11-03

This supersedes the historical validation-stopped replacement comparison in
Appendix H.4.1. Ten final-grid depth-3/width-256/dropout-0.3 targets each supply
one fixed coefficient and the original initialization. Twenty new runs cover
no-dropout controls and fitted-ridge replacements. See README.md for protocol
and checkpoint prerequisites.

## Verified results

- All 20 runs stopped by the final grid's loss-plateau rule, without budget exhaustion.
- All 20 published checkpoint hashes and 2,340 stopping-history blocks verified.
- All ten zero-penalty controls reproduce the original final-grid weights exactly.
- Median test accuracy: target 98.345%; no-dropout 97.86%; fitted ridge 97.85%.
- Ridge minus target mean paired test accuracy: -0.508 percentage points;
  descriptive seed-bootstrap 95% interval [-0.572, -0.438] percentage points.
- Ridge accuracy is lower than its target for all ten seeds; median test prediction
  disagreement is 1.655%. All targets and replacements have 100% training accuracy.
- Ridge minus no-dropout mean paired accuracy: -0.002 percentage points;
  descriptive bootstrap interval [-0.021, 0.017] percentage points.

The fitted scalar penalty fails to reproduce target test behavior for this
configuration. This does not establish impossibility for other regularizer
families. Test data did not select coefficients, stopping points, or seeds.
